## Ark 1.0.37

### Similar Games
- Game details **Similar Games** row uses Ark embedding-space neighbors (works for Steam, Epic, and cross-store titles).
- Shows enriched titles and art, cosine **distance** from the index, and skips duplicate store twins / same display name.

### Browse search
- Search **grid** stays aligned with the **dropdown** (shared debounce and no category-list fallback while you type).
- Toolbar shows **Search results** when a browse search is active.

### Install
- Run the NSIS installer from this release, or use in-app updates once `latest.yml` and assets are published per [docs/release-process.md](docs/release-process.md).
